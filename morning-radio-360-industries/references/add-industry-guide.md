# 新增行业词库指南（add-industry-guide.md）

## 词库文件规范

一个行业 = `industries/<行业id>.py` 一个纯数据文件，结构固定四块：

```python
# -*- coding: utf-8 -*-
"""<行业名>版词库（<id>.py）——面向<目标商家画像>"""
from .copy_base import build_copy

PREDICTION_HOOKS = [ ... ]   # 8 条预言钩子
CTA_TEMPLATES   = [ ... ]    # 5 条 CTA 模板（含 {kw} 占位符）
THEMES          = [ ... ]    # 14 个主题（name/lead/turn/golden/hook）
ADDRESS         = "..."      # 称呼（如"开店的老板们"）

def build(date):
    return build_copy(date, "<id>", "<行业名>", ADDRESS,
                     PREDICTION_HOOKS, CTA_TEMPLATES, THEMES)
```

### 1. 预言钩子（8 条，按年内第几天取模轮换）

公式：`我敢打赌/我有预感/我敢说 + 今天敢发【关键词】的人 + 美好预言`

- 关键词必须用【】包裹，**取最后一个【】**作为 CTA 填充词（`_extract_kw` 规则）
- 关键词选该行业商家最想要的吉利词（如五金：财源/稳当/实在/耐用；美业：变美/自信/发光）
- 句式要有变化：我敢打赌 / 我有预感 / 我敢说 / 我敢赌 交替

### 2. CTA 模板（5 条，{kw} 占位符必填）

- 每条必须含 `{kw}`，运行时自动填入当天钩子关键词，保证**首尾呼应**
- 口语化、低门槛动作：评论区打字即可
- 例：`敢不敢在评论区，打出你的【{kw}】`

### 3. 主题（14 个，= 约两周不重样的主线内容）

每个主题 4 个字段，构成三段式软广：
- `name`：主题名（2~4 字，如"开门迎财"）
- `lead`（铺垫）：行业日常场景，画面感强（如"卷帘门一拉，一天的开张就开始了"）
- `turn`（转折）：认知反转或共情点（如"柜台擦干净，货码整齐，心气也就顺了"）
- `golden`（金句）：一句可转发的正能量话（如"生意不在大小，在于天天开门"）

写作要求（用户铁律）：
- 大白话 + 家喻户晓的场景，杜绝抽象概念
- 老板/商家第一视角，共情辛苦、肯定价值
- 软广告藏在场景里（店铺、老客、手艺、进货），不硬推产品

### 4. 称呼 ADDRESS

日期问候结尾用（"今天是8月29日，星期六，{ADDRESS}早安"），如：
- 五金机电 → "开店的老板们"
- 美业 → "爱美的朋友们"

## 注册与配套（3 步）

1. **词库落位**：`industries/<id>.py`（首行相对导入 `from .copy_base import build_copy`，勿用绝对导入）
2. **注册表登记**：`industries/__init__.py` 的 `INDUSTRIES` 字典加一行 `"<id>": "<行业名>"`
3. **前端表情**（仅网页版）：`webapp_static/index.html` 的 `IND_EMOJI` 映射加一行，然后**重启 webapp**

## 素材准备（6 槽位）

放入 `materials/<行业id>/`，文件名按 `01_钩子_xxx.mp4` ~ `06_CTA_xxx.mp4` 编号开头即自动识别：

| 槽位 | 建议画面 |
|---|---|
| 01 钩子 | 店铺外观/门头，开场定调 |
| 02 交代 | 经营场景/陈列/工作环境 |
| 03 铺垫 | 细节特写（对应 lead 的场景） |
| 04 转折 | 人物/服务/互动画面 |
| 05 金句 | 有氛围感的空镜或场景 |
| 06 CTA | 温暖收尾画面（灯光/招牌/顾客） |

素材不足 6 段时，可用 ffmpeg 从长素材按叙事切 6 段：
```bash
ffmpeg -y -v error -ss <起> -t <时长> -i 源.mp4 -c copy -avoid_negative_ts make_zero 01_钩子_门店外观.mp4
```
每段 6~11 秒为宜（总设计时长约 21~24s）。

## 验证

词库写完先跑校验脚本（可检测首尾呼应/农历/封面字段/槽位完整性）：
```bash
python validate_industries.py 2026-08-29
```
再渲染样本片：
```bash
python daily_pipeline.py <行业id> 2026-08-29
```
